  # Smart Maths Quiz 🧠

A beginner-friendly Python quiz project created by Aman.

## Features
- 10 Class 8 maths questions
- Random question and answer order
- Instant feedback and explanations
- Automatic score and percentage calculation
- Option to play again
- Input validation

## Technologies Used
- Python 3
- Python IDLE
- Python built-in random module

## How to Run
1. Install Python 3.
2. Open `main.py` using Python IDLE.
3. Select **Run → Run Module** or press F5.
4. Answer the quiz questions.

## Learning Goals
This project demonstrates functions, loops, lists, dictionaries, conditional statements, user input, and randomisation.
